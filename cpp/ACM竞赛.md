## 一、现在 → 寒假：知识积累阶段（基础打底）

- **阶段定位：**蓝桥杯前的基础期，不追求难题，重在系统打牢数据结构与算法

- **数据结构：**数组、链表、栈、队列、哈希表、二叉树、简单图论基础

- **基础算法：**枚举、模拟、递归、分治、排序、二分查找、前缀和、差分

- **日常训练：**洛谷普及-/普及难度刷题，养成独立读题、写代码、调试的习惯

- **每周组队：**完成 1 道算法题，三人讨论思路、分工实现、复盘总结

- **阶段目标：**覆盖蓝桥杯全部知识点，能独立做出蓝桥杯省赛基础题

  | 周次     | 学习内容                  | 重点                                                |
  | -------- | ------------------------- | --------------------------------------------------- |
  | 第 1 周  | C++ 基础语法 + 数组       | 输入输出、循环、一维 / 二维数组、STL vector         |
  | 第 2 周  | 枚举 + 模拟               | 暴力枚举、按题意模拟、日期处理、字符串处理          |
  | 第 3 周  | 排序                      | sort 用法、结构体排序、多关键字排序                 |
  | 第 4 周  | 递归                      | 递归三要素、汉诺塔、斐波那契、递归转递推            |
  | 第 5 周  | 分治                      | 归并排序、快速排序思想、二分答案入门                |
  | 第 6 周  | 二分查找                  | lower_bound/upper_bound、整数二分、二分答案         |
  | 第 7 周  | 前缀和                    | 一维前缀和、二维前缀和、区间和查询                  |
  | 第 8 周  | 差分                      | 一维差分、二维差分、区间修改 + 单点查询             |
  | 第 9 周  | 栈                        | 栈的应用、括号匹配、单调栈入门                      |
  | 第 10 周 | 队列                      | 队列、循环队列、BFS 入门（迷宫问题）                |
  | 第 11 周 | 链表                      | 链表操作、反转链表、STL list 模拟                   |
  | 第 12 周 | 哈希表                    | map/set/unordered_map、计数、去重                   |
  | 第 13 周 | 二叉树                    | 二叉树遍历（前中后序）、层序遍历、树的基本操作      |
  | 第 14 周 | 简单图论基础              | 建图（邻接表 / 邻接矩阵）、DFS/BFS 遍历、最短路入门 |
  | 第 15 周 | 复习 1：数据结构串讲      | 栈 / 队列 / 二叉树 / 图论错题重做                   |
  | 第 16 周 | 复习 2：算法串讲          | 二分 / 前缀和 / 差分 / 递归错题重做                 |
  | 第 17 周 | 蓝桥杯模拟赛 1            | 严格计时 4 小时，完整做一套省赛真题                 |
  | 第 18 周 | 蓝桥杯模拟赛 2 + 查漏补缺 | 做第二套真题，复盘错题本，确定薄弱专题              |

## 二、寒假 → 蓝桥杯：冲刺阶段（真题实战）

- **寒假集训：**集中刷蓝桥杯历年真题，按专题突破（DP、搜索、图论、数论、字符串）

  | 周次  | 任务                                                    |
  | ----- | ------------------------------------------------------- |
  | 第1周 | 蓝桥杯真题卷（上）：刷 2019~2021 年省赛题，按专题分类做 |
  | 第2周 | 蓝桥杯真题卷（下）：刷 2022~2024 年省赛题，严格计时     |
  | 第3周 | 专题突破：只做自己薄弱的 2~3 个专题（通常是 DP / 图论） |
  | 第4周 | 全真模拟：每周 2 次，按省赛时间（4 小时）完整做一套     |

- **4月上旬~中旬：**全真模拟赛计时训练，查漏补缺，整理错题本

- **4月下旬：**蓝桥杯省赛（正式比赛）

- **5月：**蓝桥杯国赛（晋级后参加）

- **阶段目标：**拿蓝桥杯省一/国奖，以赛代练巩固基础，为下半年 ACM 赛事铺垫

## 三、6月 — 7月：过渡期 + ACM基础补强（蓄力期）

### 心态转换：从蓝桥杯到 ACM

| 蓝桥杯       | ACM（ICPC/CCPC）                  |
| ------------ | --------------------------------- |
| IO赛制       | ACM赛制                           |
| 中文题面     | **英文题面**                      |
| 可以拿部分分 | 只有 AC / WA，错一个数据点就 0 分 |
| 罚时不重要   | **罚时决定排名**                  |
| 个人赛       | **3人一队**，一台电脑             |

- 停止蓝桥杯专项训练，转向**ACM赛制思维**（英语题目/容错低、罚时、思维题多）
- 主攻：搜索、DP、图论、基础数论、字符串
- 日常训练：Codeforces、AtCoder 稳定刷题
- 可打：暑期邀请赛、省赛（练手，非正式名额赛）

## 四、8月 — 9月：ICPC / CCPC 海选关键期（核心节点）

**全年最关键报名阶段**

- **8月底**：校队组队、确定正式参赛队伍（3人一队）
- **9月上旬**：ICPC 网络预选赛（ICPC海选，拿区域赛名额）
- **9月中下旬**：CCPC 网络预选赛（CCPC海选，拿分站赛名额）
- **阶段重点**：两场一般网选不冲突、都必须打        

## 五、10月 — 12月：秋季正式线下赛（区域赛/分站赛）

- **10~12月整季**：ICPC 亚洲区域赛（多站线下）
- **10~12月整季**：CCPC 全国分站赛（多站线下）
- 规则：        
  - ICPC：每队全年最多 2 场区域赛
  - CCPC：每人全年最多 2 场普通分站赛
- **如遇周末撞期，视情况参赛**

## 六、日常训练计划（贯穿全年）

- **每周训练：**固定每周组队一节课时间完成 1 道算法题，三人协作讨论思路、分工实现、复盘
- **每月比赛：**每月组队或者个人参加 1 次洛谷大月赛
- **训练重点：**轮换专题（搜索、DP、图论、数论、字符串），补齐队内短板
- **复盘机制：**每周记录错题与易错点，每月月赛后总结 AC 率与失分原因

## 完整竞赛链路总结

**现在→寒假（知识积累）→ 寒假→蓝桥杯（冲刺拿奖）→ 蓝桥杯后ACM实战：过渡期补强 → 9月双赛事海选 → 秋冬线下区域赛/分站赛 → 冲击总决赛**
